# Кореш — голосовой микрофон 2.0 (экспериментальная сборка)

- После открытия APK и разрешения микрофона запускается foreground service с постоянным уведомлением.
- Офлайн Vosk small-ru ждёт «Бро», «Брон», «Боров», «Брок», «Броу» или «Брат»; при обнаружении издаёт короткий сигнал.
- Затем записывает речь до ~1.1 секунды тишины (максимум 16 секунд), добавляет короткую предысторию с кодовым словом и отправляет WAV 16 кГц mono в `http://127.0.0.1:8765/audio`.
- Сервер Termux должен быть запущен на **том же телефоне**; ответ озвучивается прежним Piper.
- GitHub Actions скачивает модель Vosk во время сборки и вкладывает её в APK. Первый запуск распаковывает модель в локальные файлы.

## Важные ограничения прототипа

1. Vosk с ограниченным словарём — это *приближённый* детектор кодового слова, возможны ложные срабатывания и пропуски. Для надёжного wake-word лучше специализированная локальная модель.
2. Чувствительность завершения записи по громкости (`RMS > 550`) может потребовать настройки для конкретного микрофона и шума.
3. После отправки стоит лишь трёхсекундная пауза. Во время длинного ответа Piper возможна самореакция на слово «Бро»; нужна синхронизация статуса озвучки с сервером.
4. Android может ограничивать фоновую работу при агрессивном энергосбережении. Сервис запускается из открытого приложения; сам не перезапускается после перезагрузки.
5. Не проверено сборкой на устройстве; первый APK следует считать тестовым.

## Сборка

GitHub → Actions → Build Koresh APK → Run workflow → Artifacts → Koresh-Microphone.

## Безопасность

Постоянно активный микрофон виден в системном уведомлении. Локальный звук до пробуждения не отправляется по сети. После пробуждения отправляется запись вместе с небольшим фрагментом перед ключевым словом в локальный Termux. Остановить службу можно через системное управление запущенными службами или принудительную остановку приложения.
